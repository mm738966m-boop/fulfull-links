プライバシーポリシー（fulfull SNS投稿ツール）

最終更新：2026年10月12日

fulfull株式会社（以下「当社」）は、当社が運用するSNS投稿支援ツール「fulfull SNS投稿ツール」（以下「本ツール」）において、TikTok等の外部サービスと連携する際に取り扱う情報について、次のとおり定めます。

1. 本ツールの目的と利用者

本ツールは、当社代表 森川満章が自身の公式アカウント（TikTok @morikawa__fulfull ほか）に動画を投稿し、投稿の反応を確認するための当社内部向けツールです。第三者のアカウントを操作したり、第三者の情報を収集したりすることはありません。

2. 取得する情報

  • TikTok Login Kit を通じて取得するアカウントの基本情報（表示名、アバター、ユーザーID）とアクセストークン
  • Content Posting API を通じて投稿した動画のID、公開状態、投稿日時
  • 当社が自ら用意した動画ファイル、タイトル、説明文

3. 利用目的

  • 当社公式アカウントへの動画投稿と、その公開状態の確認
  • 投稿の反応（再生数等）を当社が把握し、発信内容を改善するため

4. 保存と管理

アクセストークン等は当社の管理する端末内に暗号化されたストレージで保管し、当社の担当者以外はアクセスできません。目的を達成した情報、または連携を解除した情報は速やかに削除します。

5. 第三者提供

法令に基づく場合を除き、取得した情報を第三者に提供・販売することはありません。

6. 連携の解除

TikTokアプリの「設定とプライバシー → セキュリティ → アプリとウェブサイトの管理」から、いつでも本ツールの連携を解除できます。解除後、当社は保持するトークンを削除します。
